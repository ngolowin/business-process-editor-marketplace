# Редактор бизнес-процессов для Codex

Плагин проверяет внутренние регламенты и описания процессов на понятность, полноту, последовательность, безопасность и возможность самостоятельного выполнения.

## Что входит в репозиторий

- `plugins/business-process-editor/` — файлы плагина;
- `.agents/plugins/marketplace.json` — каталог, через который Codex находит плагин;
- `README.md` — инструкция по публикации и установке.

Пакет не содержит историю чатов, задачи Codex, документы пользователей, логины, пароли или ключи доступа.

## Как опубликовать на GitHub

Самый простой вариант — через GitHub Desktop:

1. Установите GitHub Desktop и войдите в свой аккаунт.
2. Создайте новый локальный репозиторий из этой папки.
3. Назовите репозиторий `business-process-editor-marketplace`.
4. Выполните первый commit.
5. Нажмите **Publish repository**.
6. Оставьте репозиторий публичным, если плагин должен устанавливаться без отдельного доступа. Для частного репозитория заранее пригласите нужных пользователей.

Важно: папка `.agents` скрытая, но её обязательно нужно сохранить в репозитории.

## Как установить плагин по ссылке

1. В приложении ChatGPT/Codex откройте каталог плагинов.
2. Выберите **Добавить маркетплейс плагинов**.
3. В поле **Источник** вставьте `ngolowin/business-process-editor-marketplace` или полный Git URL `https://github.com/ngolowin/business-process-editor-marketplace.git`.
4. В поле **Git ref** оставьте `main`.
5. Поле **Выборочные пути** оставьте пустым.
6. Нажмите **Добавить маркетплейс**.
7. Откройте источник **Редактор бизнес-процессов** и установите плагин.
8. Начните новый чат, чтобы Codex загрузил установленный плагин.

## Обновление

После изменений увеличьте версию в `plugins/business-process-editor/.codex-plugin/plugin.json`, отправьте изменения в GitHub и обновите marketplace в Codex. Затем переустановите или обновите плагин и начните новый чат.

## Примеры запросов

- «Проверь этот бизнес-процесс и укажи обязательные исправления».
- «Оцени, сможет ли новый сотрудник выполнить регламент без пояснений автора».
- «Подготовь структурированный черновик процесса по моим исходным данным».
